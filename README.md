# your friend · yf

一个以长期陪伴为核心、面向 Windows 和 Android 的个人 AI 伙伴。希望多年后仍能一起回顾重要往事，也能协助定闹钟、查时间、拨打电话等日常小事。

支持本地大模型与云端 API，拥有可查看、可修改、可遗忘的长期记忆，并通过按需检索控制每次对话的上下文大小。

**当前阶段：已有可运行的本机聊天与记忆验证版。Windows 安装包、Android APK、后台微调尚未实现。**

在本机双击 [start-yf.cmd](start-yf.cmd)，或执行 `uv sync --frozen --extra dev` 后运行 `.venv\Scripts\python.exe -m yf`，打开 `http://127.0.0.1:8765`。聊天需要先配置本地模型或 API；未配置时可先体验手动记忆。详见 [运行与数据管理](docs/running.md)。

## 已确认的产品方向

- 名称：`your friend`，简称 `yf`。
- 定位：以陪伴为主，按多年持续维护来设计，让用户能够回看很久以前的重要经历。
- 界面：只有一个持续聊天的主页面，以立体虚拟伙伴为中心，不提供新建对话或会话列表；回忆与设置收在抽屉中。原型已提供程序化 3D 角色、呼吸 / 眨眼 / 挥手及回应状态动作。
- 平台：Windows 桌面端、Android 端；Android 最终提供可安装的 APK。
- 模型：既能连接本地推理服务，也能接入云端 API。
- 记忆：短期上下文、长期记忆、压缩、遗忘与用户主动管理。
- 原始对话默认长期保存；模型判断记忆重要性，按价值保留细节、片段或轮廓，并根据用户反馈逐渐调整。
- 性格：可选择初始类型，在长期相处、反馈与探索中逐渐养成，并保留变化历史。
- 本地特征：原型已支持表达倾向、记忆判断侧重、补充行为描述和少量风格样例；保存在本地并随请求传给模型，支持历史回退。
- 学习与训练：提供“学习成长”开关，开启后后台静默整理对话、微调与评估，并自动启用合格版本；支持查看、暂停与回退，训练能力依所选模型与设备而定。
- 性能：每轮只检索相关记忆，给上下文设置明确预算；避免每次重新处理全部历史。
- Android 第一阶段连接电脑或自托管服务；手机端完整离线运行放在后续阶段。
- 后续可将服务迁到 Mac mini 等常开设备；记忆数据与所用模型、当前电脑分离。
- 接入设备已有的日常能力：闹钟、时间、电话；具体交互与平台支持需分别验证。
- 本地开发目录：`E:\code_product\your_friend`。

## 框架建议

使用 Flutter 共用 Windows / Android 客户端，使用 Python + FastAPI 构建模型与记忆服务。第一阶段以个人使用为目标，由同一个服务持有记忆，两个客户端连接它。

模型推理与记忆存储是两个独立选择：即使选择云端模型，也可以把主记忆库保存在自己的电脑或自托管服务器上。发送到云端模型的当轮消息、摘要和检索片段仍会离开设备，需要在界面中明确展示。

Windows 端按桌面应用设计，管理本机服务的启动、健康检查和退出。Android 端连接已配置的服务，并在手机本地执行手机能力。电脑关机后，手机无法继续访问该电脑上的模型和记忆；已经成功设置的本地闹钟应继续由手机系统负责。需要聊天服务持续可用时，可以改连 Mac mini 等常开主机。

## 后续开发原则

先完成「陪伴聊天 → 保存重要回忆 → 跨会话召回 → 按时间回顾 → 用户纠错或删除」的完整闭环，再接入日常设备能力。备份与恢复从数据层初期就纳入设计；语音、附件等扩展逐步加入。框架和功能范围的待定项见决策文档。

运行数据、聊天记录、向量、API 密钥和 APK 签名材料不进入 Git。开源许可证尚未选择，本次不默认添加许可证。

原型的限制、当前遗忘参数与实际可用能力以运行文档为准；设计文档中的后续目标不表示已经实现。
